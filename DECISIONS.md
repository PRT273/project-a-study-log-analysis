\# Design Decisions



\## Why a simple CSV dataset



I chose a CSV file because the data is small, personal, and manually collected.

Using a database would add unnecessary complexity at this stage.



\## Why pandas and matplotlib



pandas provides clear and readable data manipulation for tabular data.

matplotlib is sufficient for simple and interpretable visualizations.



\## What I did not do



\- I did not use machine learning models, because the dataset is too small.

\- I did not optimize performance, as clarity was the priority.



\## Future ideas



\- Log data automatically

\- Add weekly summaries

\- Extend the project into a small web application
