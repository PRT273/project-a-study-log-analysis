# Study Log Analysis


This project is a small personal data analysis based on my daily study records during exam preparation.


## Motivation


During long-term self-study, I often felt busy but could not clearly explain how my study time was actually distributed across different subjects.


Instead of relying on subjective feelings, I decided to record my study activities and analyze them using data.


This project is my first practical attempt to use Python for simple data analysis and self-reflection.


## Dataset


The dataset is manually collected and stored in `Data/study_log.csv`.


Each record contains:

- `date`: the study date  

- `subject`: the subject studied  

- `hours`: time spent (in hours)  

- `note`: short personal notes  


Because the data is self-recorded, the dataset is small and personal, but it reflects my real study behavior without external preprocessing.


## Analysis


The analysis is implemented in a Jupyter notebook and focuses on:


- Loading and exploring the dataset using pandas  

- Aggregating total study time by subject  

- Visualizing study time distribution with matplotlib  


The goal of the analysis is clarity and interpretability rather than complex modeling.


## Results


The results show how my study time is distributed across different subjects during the recorded period.
